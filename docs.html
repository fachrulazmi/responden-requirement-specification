Tutorial Penggunaan

Panduan lengkap untuk mengelola spesifikasi kriteria responden dan kerangka variabel penelitian Anda menggunakan RCS Workspace.

01

Konfigurasi

Mulai dengan menentukan identitas dasar proyek dan tautan kuesioner Anda. Bagian ini penting untuk pelabelan dokumen, perhitungan estimasi, dan manajemen akses.

  • Nama Lengkap: Identitas pemilik proyek atau peneliti.
  • Nama Survey: Judul penelitian atau topik survey yang sedang dikerjakan.
  • Durasi: Estimasi waktu pengerjaan dalam hari.
  • Jumlah Responden: Target total sampel yang ingin dicapai.
  • Link Google Form (Tes/Utama): Simpan tautan kuesioner Anda agar mudah diakses dan ikut tersimpan dalam file ekspor data.
02

Definisi Demografi

Tentukan kriteria responden yang Anda butuhkan. Anda dapat menambah kategori baru dan menentukan persentase distribusi untuk setiap opsi.

  • Klik + Tambah Kategori untuk membuat kelompok demografi baru (misal: Usia, Pekerjaan).
  • Gunakan + Sisipkan Opsi untuk menambah pilihan jawaban di dalam kategori.
  • Masukkan label dan nilai persentase. Pastikan total persentase dalam satu kategori logis (umumnya 100%).
03

Kerangka Variabel

Susun pertanyaan untuk Variabel X (Independen) dan Variabel Y (Dependen) dengan skala Likert yang seragam.

  • Definisi Skala Likert: Masukkan opsi skala Anda dipisahkan dengan koma (misal: Sangat Tidak Setuju, Tidak Setuju, Setuju, Sangat Setuju).
  • Tambah Pertanyaan: Klik ikon plus (+) pada masing-masing variabel untuk menambah baris pertanyaan.
  • Distribusi: Masukkan angka distribusi untuk tiap pilihan skala pada setiap pertanyaan.
04

Contoh Pengisian

Berikut adalah gambaran bagaimana Anda bisa mengisi spesifikasi untuk survei sederhana:

01. Konfigurasi

  • Nama Survey: Survei Kepuasan Aplikasi Food-Delivery
  • Durasi: 3 Hari
  • Responden: 100
  • Link Utama: https://docs.google.com/forms/...

02. Demografi

  • Kategori: Domisili → Jakarta (40%), Bandung (30%), Lainnya (30%)
  • Kategori: Pekerjaan → Mahasiswa (50%), Karyawan (50%)

03. Variabel (Skala: STS, TS, S, SS)

  • ID: X1 → "Aplikasi mudah digunakan" (Distribusi: 5, 15, 50, 30)
  • ID: Y1 → "Saya akan menggunakan aplikasi ini lagi" (Distribusi: 0, 10, 40, 50)
05

Manajemen Data

RCS Workspace menyimpan data secara otomatis di browser Anda, namun sangat disarankan untuk melakukan ekspor manual.

  • Ekspor JSON: Menyimpan seluruh konfigurasi Anda ke dalam file dengan format rcs_hhmmss_ddmmyyyy.json.
  • Impor Data: Mengunggah kembali file JSON yang pernah Anda simpan sebelumnya.

Estimasi Biaya

Fitur ini memberikan gambaran kasar biaya berdasarkan durasi pengerjaan dan jumlah responden. Tarif dasar saat ini adalah:

Biaya Durasi: Rp. 25.000 / Hari
Biaya Responden (Umum): Rp. 350 / Orang

Aturan Biaya Khusus (Durasi 1 Hari):

≤ 50 Responden: Rp. 500 / Orang
75 Responden: Rp. 400 / Orang
≥ 100 Responden: Rp. 350 / Orang
